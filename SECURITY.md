# Security and data handling

This is an offline educational demonstrator. Do not add real patient, supplier, SAP or company records. No credentials are needed to run it. `.env`, private keys, local environments and database journals are ignored. Git ignores do not remove secrets already committed: revoke exposed credentials and review history before publication.

Report sensitive findings privately through the repository owner's GitHub profile contact options if available; never post a credential or private dataset in a public issue. No production security support or compliance certification is implied.
