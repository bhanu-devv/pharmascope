# Roadmap

These are proposed improvements, not delivered features.

1. Replace specialized workbook runtime with a documented portable generator and test native spreadsheet recalculation.
2. Assemble and validate a `.pbix` report with shared date/category dimensions and protected budget measures.
3. Add supplier/category summary grain and invoice exception dashboard drill-down.
4. Add receipt/invoice lines, partial delivery, returns, unit-of-measure and currency masters.
5. Add consumption/COGS, lots and expiry data before inventory turnover or stockout modeling.
6. Introduce independently planned budgets and backtested forecasts with explicit cutoffs.
7. Add ingestion contracts, exact decimal arithmetic, domain review and operational security before any real-data use.
