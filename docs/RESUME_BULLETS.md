# Project highlights

**PharmaScope — Pharmaceutical Procurement & Financial Analytics | Portfolio Case Study**
*Python, SQL/SQLite, Advanced Excel, Power BI DAX (implementation assets), Power Query (template)*

- Built a reproducible synthetic procurement analytics case study covering **20,000 purchase orders**, **50 suppliers**, and **500 materials**, with budget variance, purchase price variance, supplier delivery and invoice exception metrics.
- Developed an offline interactive finance dashboard and formula-driven Excel model featuring monthly spend-versus-budget reconciliation, supplier scorecards and **0–20%** procurement price-shock scenarios.
- Modeled relational supplier/material/purchase-order data and documented SAP-style purchase-to-pay processes; prepared DAX measures and Power Query assets for a future Power BI Desktop report.
