# Contributing

Keep examples synthetic. Describe the problem and expected result in an issue or pull request. Use Python 3.11/3.12, rebuild data/dashboard when their inputs change, and run both test scripts. Explain metric or grain changes in the data dictionary and financial calculations guide. Include screenshots for UI changes. Do not commit virtual environments, tokens, private records or oversized exports. Review the publication status and licensing with the owner before reusing code elsewhere.
